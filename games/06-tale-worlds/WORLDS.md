# ワールドの作り方（ゲーム 06「ものがたりの世界をめぐる」）

これまでの集の「見るだけの場面」を、主人公が歩きまわれるワールドにする手順です。見本は `worlds/8-01.js`（第 8 集 01「城下町の大通り」から作った物）。

## 読む物

1. `CLAUDE.md`、`docs/taste.md`（持ち主の好み。とくに「昔の家庭用ゲーム機のファンタジー RPG の人と敵（第 13 集）」の節）
2. `games/06-tale-worlds/core.js` の先頭のコメント（ワールドで使える道具 `G.*`）
3. `games/06-tale-worlds/worlds/8-01.js`（見本。書き方と密度をこれに合わせる）
4. もとの場面の HTML（`worlds/list.js` の id が「集-番号」。例 `12-07` は `game-looks-12/07-*.html`）と、それが読む部品集の先頭のコメント
5. 町の人の作り：`game-looks-13/pack-tale.js` の先頭のコメント（`TL.person` の `size` `hair` `outfit` `hat` `hold` `colors` `head`）

## ファイル

- 書くのは `worlds/<id>.js` の 1 枚だけ。`TALE_WORLD('<id>', G => { … })` の形。
- `core.js`、`worlds/list.js`、`retro.js`、`pack-*.js`、もとの場面のファイルは変えない（直したい所があれば、まとめて報告する）。
- ワールドが読む部品集は `worlds/list.js` の `packs` に書いてある（足りないときは報告する）。

## もとの場面からの移し方

1. **空・光・霧・地面・家・小物・遠景**は、もとの場面のコードをほぼそのまま写す。`K.lights(scene, G.renderer, { … })`、`R.ground` の `H` は `G.ground(H)` にもわたす。
2. **主役・道（path）・カメラ・`K.loop`・`R.crt`** は消す（土台がやる）。毎コマ動く物（旗・水・けむり・鳥・`F.tick` など）は `G.tick((t, dt, P) => { … })` へ。`P` は主人公の位置 `{ x, y, z }`。
3. **人**は `R.actor` をやめ、`TL.person({ size, hair, outfit, hat, hold, head, colors })` にする（主人公と同じ 4.5 頭身の作り。背の高い人は `size: 'tall'`、子どもは `'child'`）。役で服を変える（衛兵＝`guard`＋`helm`＋`spear`、魔法使い・学者＝`robe`＋`wizard`／`hood`、店の人＝`apron`、職人＝`worker`）。`F.wear`（R.actor 用）は使わない。
4. **ねこ・鳥などの動物**は もとのまま `R.cat` `R.bird` を使い、話せるねこは `G.npc(cat, { idle: t => R.catPose(cat, 'sit', t), … })`。

## 遊べるようにする

- **当たり判定**：置いた物ごとに `G.solid(物, 形)`。
  - 家・塔・城など屋根のある大きな物は、見た目の箱ではなく **かべの大きさ** で `G.box(x, z, w, d, y0, y1, ry, true)`（`true`＝上に乗れない）。ひさし・看板の下は歩けるように。
  - 木は `'trunk'`、街灯・旗ざおは `'trunk', { r: .15 }`、たる・はちは `'round'`、木箱・台・ベンチ・荷車は `'box'`（上に乗れる）、草・花・旗の綱は `'none'`。
  - 見えない かべ・段・足場は `G.box` と `G.circle`。水の中・がけの外など入ってほしくない所は、かべか `G.bounds` でふさぐ。
- **地面**：`G.ground(H)`。高い所（橋・屋上・浮いた島・塔の通路）は、上に乗れる `G.box` を足場として置く（見た目の床と高さをそろえる）。0.42 m までの段はそのまま のぼれる。ジャンプは 0.9 m ほど。
- **歩ける はんい**：`G.bounds(x0, x1, z0, z1)`。はんいの外が見えないなら、そこに柵・かべ・がけ・水など「行けない理由」が見えるようにする。
- **はじめの場所**：`G.spawn(x, z, 向き)`。いちばん見せたい物（城・巨像・塔など）が正面に見える向き。
- **自動で歩く道**：`G.tour([[x, z], …])`（`?auto=1` とサムネイル用）。かべにぶつからず、見どころをめぐる 6〜12 点。
- **のぼれる所**を 1 つ以上：木箱の山、石だん、屋根の上、見晴らし台、橋の上など。ジャンプで行ける高さ（1 段 0.9 m まで）で。

## もう少し作りこむ（持ち主の頼み「もう少し詳細に」）

- もとの場面に、その世界らしい小物・人・動く物を足す（屋台、たる、花、洗たく物、看板、ランプ、鳥、ねこ、けむり、水しぶき など）。
- **話せる人を 6〜10 人**（その場所らしい仕事と服で。見回り・店・子ども・お年より・旅人・職人 など）。動く人は `path`（`THREE.CatmullRomCurve3`）で歩かせる。
- **しらべられる物を 2〜5**（`G.sign(x, y, z, { name, lines })`：看板・碑・ふしぎな物・景色）。
- 文は日本語で、かなを多めに、短く（1 行 20 字ほど、1 ページ 1〜2 行）。`lines` は 1 回話すごとに 1 つずつ進む。1 回の会話で何ページか見せたいときは配列にする（`[['1 ページめ', '2 ページめ'], '次に話したとき']`）。
- 人の名前は役の名前（「見回りの衛兵」「パン屋のおかみさん」）。既存の作品の名前・人物・用語は使わない。
- ほかのワールドのことを少し話す人がいると、世界がつながって楽しい（「北には空を泳ぐくじらの町があるそうだ」など）。

## 書き方の決まり

- コメントと文は日本語。ファイルの先頭に「もとの場面」「どんな場所か」「ゲームにするために足した物」を 2〜4 行で。
- **行のうしろに `//` のコメントを書いたら、その行にはもう処理を書かない**（コメントのうしろの処理は消える。何度もこれで壊れた）。コメントは行の最後か、別の行に。
- 箱の組み合わせで人・家・木を作らない（部品集の物を使う）。段や台を `R.geo().box` で作るときは、石や木のテクスチャ（`T.stone` `T.planks` など）をはる。

## 確かめる

1. `node --check games/06-tale-worlds/worlds/<id>.js`
2. `node tools/tale-check.mjs <id>` … エラー、全員に話しかけてもエラーが出ないか、自動で歩けるか、はじめの場所がかべの中でないか。「問題なし」になるまで直す。
3. `node tools/cap.mjs check "games/06-tale-worlds/index.html?dev=1&w=<id>&auto=1"` … `tools/out/` の `-sheet.jpg` を **自分の目で見る**。主人公が見えるか、もとの場面の良さ（大きい物・遠くの物・光）が出ているか、町の人がいるか、物にめりこんでいないか。
4. `node tools/cap.mjs check "games/06-tale-worlds/index.html?dev=1&w=<id>&at=x,z,向き&talk=1"` … 話している絵（吹き出しが出る）を 1 枚見る。
5. 高い所に乗れることも `?at=` で 1 回見る。

できたら、`worlds/list.js` の `ready` は変えずに報告する（まとめて変える）。
