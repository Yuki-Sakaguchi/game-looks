# 頼み方のひな形

好みの 2 つのテイストで、生成 AI に絵を作ってもらうときの頼み方です。かっこの中を書きかえて、そのまま貼ってください。決めていない項目は「おまかせ」と書けば、AI が案を出して進めます。

Claude Code でこのリポジトリを開いているときは、テイストの名前を書くだけで、対応するスキル（`.claude/skills/`）が読まれます。ほかの AI に頼むときは、ひな形の最後の「読む物」の行が道案内になります。

| テイスト | 呼び名 | 見本 | スキル |
|---|---|---|---|
| A | こまかいローポリ | `game-looks-7/01`〜`10` | `look-lowpoly` |
| B | 描きこんだテクスチャとブラウン管 | `game-looks-7/11`〜`20` | `look-retro-crt` |

## 1. 見るだけの場面を 1 つ足す

```text
第 7 集に、テイスト（A こまかいローポリ ／ B 描きこんだテクスチャとブラウン管）で場面を 1 つ足してください。
- 場面: （例）雨の日のバス停で、バスを待つ子ども
- 主役とカメラ: （例）かさをさした子どもを、うしろから追う
- 時間と天気: （例）夕方、こさめ、街灯がつきはじめる
- 色: （例）灰色がかった青と、かさの黄色。おまかせでもよい
- 入れたい物: （例）バス、ぬれた道、水たまり、ねこ
読む物: docs/taste.md と、.claude/skills/ の look-lowpoly（A）か look-retro-crt（B）。
作ったら tools/cap.mjs で絵を見て、点検表で確かめてから、サムネイルと一覧まで仕上げてください。
```

## 2. 同じ場面を、2 つのテイストで見くらべる

```text
次の場面を、テイスト A（こまかいローポリ）とテイスト B（描きこんだテクスチャとブラウン管）の両方で 1 つずつ作ってください。
- 場面: （例）灯台のある岬の朝
- 主役とカメラ: （例）犬をつれて歩く人を、うしろから追う
どちらも第 7 集に続きの番号で足し、2 枚をならべた絵を見せてください。
読む物: docs/taste.md、.claude/skills/look-lowpoly、.claude/skills/look-retro-crt。
```

## 3. 場面をまとめて足す

数を増やすときは、先に 1 つ仕上げて、絵を見てから広げます。

```text
第 7 集に、テイスト（A ／ B）で場面を（5）つ足してください。
- 題材: （例）日本のいなかの四季 ／ おまかせ
- 場面どうしで、場所・時間・天気・主役がかぶらないようにしてください。
まず 1 つめを仕上げて絵を見せてください。良ければ残りを作ってください。
読む物: docs/taste.md と、.claude/skills/ の対応するスキル。
```

## 4. 場面から、あそべるゲームを作る

```text
game-looks-7 の（番号と名前）をもとに、操作して遊べるゲームを games/ に作ってください。
- あそび: （例）村の中を歩いて、ねこを 5 ひき見つける
- 操作: キーボードとマウス、タッチ（画面の左でスティック、右でボタン）
- 終わりの条件: （例）5 ひき見つけたらクリア
絵はもとの場面のテイストのまま変えないでください。部品集は写さず、../game-looks-7/ の物を読みこんでください。
読む物: README の「あそべるゲームを足すとき」、docs/taste.md、.claude/skills/ の対応するスキル。
```

## 5. 部品を足す・直す

```text
テイスト（A の model.js ／ B の retro.js）に、（例: バス、電柱、傘をさした人の姿勢 ／ トタン屋根とブロックべいのテクスチャ）を足してください。
- どの場面で使うか: （例）雨の日のバス停
足した物は、一覧のページ（model-sheet.html ／ retro-sheet.html）にも並べ、部品集の先頭のコメントに使い方を書いてください。
部品集は第 7 集の全ページが使っています。直したあと、見本の 01 と 11、ほか 2〜3 ページで絵がくずれていないことを確かめてください。
```

## 6. 絵が好みとちがうとき

感想は、そのまま書けば足ります。AI は `docs/taste.md` に記録して、次から守ります。

```text
（番号）を見ました。（例: 人が小さい ／ 色が多くてごちゃごちゃ ／ ブラウン管が強すぎて見づらい ／ まだ箱っぽい）です。
直してください。この感想は docs/taste.md にも足してください。
```

## AI が守ること（どの頼み方でも同じ）

- 人・家・木を箱（BoxGeometry）の組み合わせで作らない。部品集（`model.js` か `retro.js`）の物を使う。
- 絵は `tools/cap.mjs` で撮って、自分の目で見てから「できた」と言う。エラーが出ないことと、良い絵であることは別。
- 確かめていないこと（実機のスマホでの速さ、場面の後半）は、確かめたと書かない。
- 既存のゲームや作品の名前・キャラクター・画面は写さない。商品名も書かない。
- 数が多いときは、1 つ仕上げて絵を見せてから広げる。
